# Quick AI – AI-Powered Full Stack Web Application

## Description
Quick AI is a full-stack AI-powered web application that provides multiple AI tools on a single platform. Users can generate AI content, edit images, review resumes, and interact with the community.

## Technologies Used
- React.js
- Node.js
- Express.js
- PostgreSQL (Neon)
- Clerk Authentication
- Cloudinary
- Google Gemini API
- ClipDrop API
- HTML5
- CSS3
- JavaScript

## Features
- AI Image Generation
- AI Background Removal
- AI Object Removal
- AI Blog & Article Generation
- AI Resume Review
- Community Feed (Like & Share)
- Secure User Authentication
- Subscription Management

## Project Structure

client/
- React Frontend

server/
- Node.js + Express Backend
